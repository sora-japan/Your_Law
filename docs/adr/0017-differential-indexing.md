# ADR-0017: 未施行版は現行版との差分のみをインデックスする

## Context and Problem Statement

ADR-0016 により全バージョンを保持する方針としたが、
全バージョンの全条をそのままインデックスすると重複が大量に発生する。

地方税法は33バージョン × 1,348条 = 44,484チャンクとなり、
同一条文が最大33回インデックスされる。検索結果が同じ条文で埋まる。

複数バージョンを持つ 856 法令を対象に、
現行版と各未施行版を条単位で比較して差分を実測した。

| 項目 | 件数 |
|---|---|
| 全バージョンの全条を持つ場合 | 387,748 |
| 現行版の全条 + 未施行版の差分のみ | **23,608** |
| 削減率 | **約94%** |

地方税法単体では 44,484 → 1,400（97%削減）。
差分は施行日が先のものほど大きくなる傾向がある
（20260924で1件 → 20270101で13件 → 20271001で82件 → 20290401で91件）が、
同一施行日の6バージョンでは13〜53件と幅があり、
後の日付のほうが差分が小さい箇所もあるため単調増加ではない。

## Decision Drivers

* 同一条文が検索結果を占有するのを避けること
* 埋め込みの計算コストとインデックスサイズを抑えること
* 改正の内容を失わないこと

## Considered Options

1. 全バージョンの全条をインデックスする
2. 現行版のみインデックスし、未施行版は扱わない
3. 現行版は全条、未施行版は現行版と差分のある条のみインデックスする

## Decision Outcome

Chosen option: "現行版は全条、未施行版は現行版と差分のある条のみインデックスする", because
選択肢1は387,748チャンクとなり、その大半が同一内容の重複である。
検索結果の品質を著しく下げる。

選択肢2は「法改正が自分に関係あるかを知らせる」という本プロダクトの
主機能そのものを失う。

選択肢3は94%の削減を達成しつつ、改正内容を保持する。
未施行版に差分チャンクが存在すること自体が「その条が変わる」という情報であり、
主機能の実装と重複排除が同一の仕組みで実現される。

差分の判定は条単位で行い、以下の3種類を検出する。

* 変更: 両バージョンに存在し、本文が異なる条
* 追加: 未施行版にのみ存在する条
* 削除: 現行版にのみ存在する条（扱いは ADR-0018 を参照）

### Consequences

* Good: インデックスが 387,748 → 23,608 に削減される
* Good: 差分チャンクの存在が、そのまま改正の検知情報になる
* Good: 埋め込みの計算回数が約1/16に減り、初期構築時間が短縮される
* Bad: 初期構築時に全バージョンをパースして比較する処理が必要になる
  （856法令分、実行に数分を要する）
* Bad: 差分チャンク単体では文脈が不足する場合がある
  → 現行版の同一条へのリンクをメタデータに持たせる
* Bad: 現行版が更新されるたびに、全未施行版の差分を再計算する必要がある
