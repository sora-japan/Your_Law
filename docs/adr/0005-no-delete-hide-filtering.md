# ADR-0005: `Delete` / `Hide` 属性に基づく除外処理を実装しない

## Context and Problem Statement

法令標準XMLスキーマには、条項の効力と表示に関する2つの属性が定義されている。

* `Delete`(default: false) — 項目が効力を有さないものとして削除扱いとされている場合に `true`
* `Hide`(default: false) — 項目が非表示である場合に `true`

効力を有さない条文を「この法律が適用されます」と回答すれば明確な誤りになるため、
除外処理が必要かを判断するために全法令を対象に出現数を調査した。

| 属性 | false | true |
|---|---|---|
| Delete | 24,647 | **0** |
| Hide | 48,697 | **1** |

`Hide="true"` の1件は `327CO0000000058`（鹿児島県大島郡十島村の区域に関する法令の
適用に関する政令）の本則の項で、`<Sentence WritingMode="vertical"/>` と
**テキストが空**であった。同法令の `MainProvision` には `Extract="true"` が付いており、
本則が収録されていない法令の形式的なプレースホルダと考えられる。

## Decision Drivers

* 効力のない条文を根拠として提示しないこと
* 実装しない処理を増やさないこと（使われないコードは保守の負債になる）
* 実データに基づいて判断すること

## Considered Options

1. `Delete="true"` / `Hide="true"` を除外する処理を実装する
2. 除外処理を実装せず、空テキストのチャンクを捨てる処理のみ実装する

## Decision Outcome

Chosen option: "除外処理を実装せず、空テキストのチャンクを捨てる処理のみ実装する", because
`Delete="true"` は全法令で0件であり、除外処理を書いても一度も実行されない。
`Hide="true"` は1件のみで、かつテキストが空であるため、
空テキストのチャンクを生成しないという別の処理によって自動的に対象外となる。

なお本判断は**条・項レベルの効力**に限る。法令そのものの効力（廃止済み・未施行）は
別の軸であり、API メタデータの `repeal_status` / `remain_in_force` /
`current_revision_status` による判定が別途必要である（別ADRで扱う）。

### Consequences

* Good: 不要な処理を実装せずに済み、コードが単純になる
* Good: 判断が実データの全件調査に基づいており、根拠を示せる
* Bad: 将来 e-Gov のデータ更新で `Delete="true"` が出現した場合、静かに取りこぼす
  → 差分更新時に属性値の分布を再確認する運用が必要
* Bad: 一括ダウンロードのデータに限った調査であり、
  API 経由で取得したデータに同じ性質があるかは未検証
