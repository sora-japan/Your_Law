# ADR-0012: ルビの読み仮名を本文から除外し、`Rt` の `.tail` は保持する

## Context and Problem Statement

法令XMLには振り仮名が `<Ruby>藉<Rt>しや</Rt></Ruby>` の形式で記述されている。
`Ruby` が 27,873 件、`Rt` が 27,944 件存在する。

テキスト抽出で全要素の `.text` を単純に連結すると、`Rt` の内容（読み仮名）が
本文に混入し、「慰藉**しや**する等のため」のような文字列になる。

実装方法として、再帰処理で `Rt` に到達したとき `continue` で
ループごとスキップする方法が考えられるが、`continue` は
その要素の `.tail`（閉じタグ以降のテキスト）の処理もスキップする。

全10,702件を対象に `Rt` の `.tail` を調査したところ、
空白以外の文字が入るケースが **72件** 存在した。
内訳はひらがな1文字が中心（「い」23件、「つ」12件、「う」11件 ほか）、
漢字が1件（「素」）。熟語の一部にのみルビが振られている場合に発生する。

## Decision Drivers

* 読み仮名が本文に混入しないこと
* 本文の文字が欠落しないこと
* 同種の除外（表・数式など）を将来追加する際に同じ方式で書けること

## Considered Options

1. `iter()` で全要素を平坦に走査し、`Rt` をスキップする
2. 再帰処理で `Rt` に到達したら `continue` する
3. 再帰処理で `Rt` の再帰呼び出しのみスキップし、`.tail` は拾う

## Decision Outcome

Chosen option: "再帰処理で `Rt` の再帰呼び出しのみスキップし、`.tail` は拾う", because
選択肢2は `.tail` も同時に捨てるため、調査で確認した72箇所で本文が欠落する。

選択肢1は `Rt` 自体はスキップできるが、配下の要素は別途走査対象として
返ってくるため「配下ごと除外」ができない。今回の `Rt` は内容がテキストのみのため
動作するが、将来 `Table`（TableColumn 353万件）や `ArithFormula`（6.6万件）を
別扱いする際に同じ方式では書けず、実装のやり直しになる。

選択肢3は、再帰呼び出しを行わないことで配下全体が走査対象から外れる。
`.tail` は要素の外側にあるため、再帰とは独立して取得できる。

### Consequences

* Good: 読み仮名が除外され、かつ本文の欠落が発生しない
* Good: 同じ形式で他タグの配下ごと除外を追加できる
* Good: 判断が全件調査（72件）に基づいており、根拠を提示できる
* Bad: `continue` と比べて分岐が1つ増え、実装がわずかに複雑になる
* Bad: 除外対象タグが増えた場合、条件式が肥大化する
  → 除外タグを定数の集合として外出しすることで対応する
