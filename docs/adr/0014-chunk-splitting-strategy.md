# ADR-0014: チャンクは条単位を基本とし、閾値超過時は項・号へ段階的に降りる

## Context and Problem Statement

RAG の検索対象となるチャンクを、法令XMLからどの単位で切り出すかを決める必要がある。

考慮すべき制約が2種類ある。**この2つは性質が異なる。**

**1. 技術上限**
埋め込みモデル（ruri-v3-310m / bge-m3）の最大入力長は 8,192 トークン。
これを超えた分は切り捨てられるため、超過は情報の欠落に直結する。
ruri-v3-310m のトークナイザで実測したところ、法令文ではトークン数÷文字数が
41.8%〜55.2%（平均約47%）であり、**8,192 トークンは約17,000文字に相当**する。

**2. 検索精度の観点からの適切なサイズ**
埋め込みはテキスト全体を1つのベクトルに圧縮する。長いチャンクほど
複数の話題が平均化され、特徴がぼやけて検索でヒットしにくくなる。
逆に短すぎると「前項の規定は」のような参照が意味を失う。
**技術上限と最適サイズは別物であり、8,192トークンは後者ではない。**

### 条の文字数分布（現行版）

ADR-0015 で特定した現行版 8,997 法令の `MainProvision` 配下の `Article`
について、テキスト抽出・正規化後の文字数を測定した。

| 区間 | 件数 | 割合 | 累積 |
|---|---|---|---|
| 〜200 | 114,378 | 47.3% | 47.3% |
| 201〜500 | 77,239 | 31.9% | 79.2% |
| 501〜1,000 | 31,723 | 13.1% | 92.3% |
| 1,001〜2,000 | 13,065 | 5.4% | 97.7% |
| 2,001〜5,000 | 4,555 | 1.9% | 99.6% |
| 5,001〜8,000 | 611 | 0.25% | 99.8% |
| 8,001〜 | 458 | 0.19% | 100% |

条の総数は **242,029**。最大は **246,498 文字**（普通交付税に関する省令 第12条）。

| 500 | 50,412 | 20.8% |
| 1,000 | 18,689 | 7.7% |
| 2,000 | 5,624 | 2.3% |
| 8,000 | 458 | 0.19% |

号（`Item`）の総数は 464,010、最大は 33,627 文字。

|---|---|---|

### 測定の経緯

当初は一括ダウンロードの 10,702 ファイル全体を対象に測定していたが、
同一法令の複数バージョン（ユニークな法令IDは 8,997）が含まれており、
条の件数が重複で水増しされていた（条 551,320 件、500文字以下 74.0%）。
現行版のみに絞ることで総数は半分以下になり、500文字以下の割合は 79.2% に上昇した。
長い条文を持つ大規模法令が複数バージョン重複していた影響である。

**本ADRの数値はすべて現行版のみの再測定値である。**
ただし以下の2点は重複を含む当初測定の値であり、現行版では再測定していない。

* 長大条文の構成要素（8,001文字超の条について、1条あたり平均 `Sentence` 156個、
  `TableColumn` 40個、`Item` 38個、`Column` 32個、`Paragraph` 25個、`Subitem1` 18個）。
  長さの原因が自然文ではなく構造化された項目の量であるという傾向の把握に用いた
* 項（`Paragraph`）の文字数分布

## Decision Drivers

* 法令を扱うため、意味を壊す分割は誤った回答に直結する
* チャンクの境界が出典の単位と一致していること（根拠提示が主機能のため）
* 技術上限を超えて情報が切り捨てられないこと
* 断片化しすぎると、チャンク単体では文脈が失われ根拠として使えない

## Considered Options

1. 固定文字数（200〜500文字程度）で機械的に分割する
2. 条単位で固定し、上限超過分は切り捨てる
3. 最初から項または号の単位で一律に分割する
4. 条を基本とし、閾値を超えた場合のみ項・号へ段階的に降りる

## Decision Outcome

Chosen option: "条を基本とし、閾値を超えた場合のみ項・号へ段階的に降りる"

### なぜ条を基本単位とするか

**1. 条は立法時に設計された意味の単位である**

法令の条は、一つの規範・定義・手続きを表す単位として立法段階で区切られている。
機械的な文字数分割と違い、**区切りの妥当性を人間が保証済みの境界**である。

**2. 出典の単位と一致する**

法令を引用する標準形式は「◯◯法第◯条」であり、条が引用の最小単位となる。
本プロダクトは根拠となる条文を出典つきで提示することを中核とするため、
チャンク境界と出典境界が一致していれば、検索結果をそのまま根拠として提示できる。
固定文字数で分割すると「第◯条の途中から◯文字」という提示不能な単位になる。

**3. 条内参照が閉じる**

法令には「前項の規定は」「前条に規定する」といった相対参照が頻出する。
実データでも `印紙犯罪処罰法` 第二条第二項に「前項ノ未遂罪ハ之ヲ罰ス」を確認した。
項単位で切ると参照先がチャンク外になり、単体では意味をなさない。
条単位であれば「前項」参照は同一チャンク内で解決する。

**4. 実測分布が条単位と整合する**

現行版の条の 79.2% が 500 文字以下、97.7% が 2,000 文字以下であった。
多くの条が、追加の分割なしに検索に適したサイズへ自然に収まる。

### 他の選択肢を採らない理由

選択肢1（固定文字数）は、上記2の理由により出典として提示できない単位を生む。
法令を扱う本プロダクトでは採用できない。

選択肢2（切り捨て）は情報の欠落を招く。法令の条文が途中で失われることは許容できない。

選択肢3（一律に項・号）は、97.7%を占める 2,000 文字以下の条まで不必要に分割し、
条単位で完結している意味のまとまりを壊す。号単位では1チャンクが
数十文字の断片になる場合があり、単体では文脈が失われる。

### 閾値の扱い

分割を発動する閾値は、**技術上限（8,192トークン ≒ 約17,000文字）ではなく、
検索精度から決定すべき値**である。現時点でその値は未確定であり、
第3週のチャンク設計で以下を同一の評価データで比較し、実験的に決定する。

* 条単位＋閾値を変えた段階分割（200 / 500 / 1,000 / 2,000 / 8,000）
* 項単位で一律
* 固定文字数＋オーバーラップ

200 文字は一般に検索精度が高いとされる値だが、その根拠の多くは英語圏の記述であり、
日本語かつ法令という文体で同じ傾向が出るかは未検証である。
また 200 文字では条の 52.7% が分割対象となり、
本ADRが掲げる「条を基本単位とする」理由と衝突するため、検証対象として扱う。

それまでは暫定的に **2,000 文字**を閾値として実装を進める。
2,000 文字を超える条は 2.3%（5,624件）にとどまり、
大半の条は分割なしで 1 チャンクに収まる。

### 号でも閾値を超える場合の扱い

号まで降りてもなお閾値を超えるもの（暫定閾値 2,000 文字で 281 件、号全体の 0.06%）
については、文字数による機械的分割を適用する。精度低下を抑えるため、
閾値の手前で直近の句点（「。」）を探して分割位置とする。

号の下位（`Subitem1` 以下、イ・ロ・ハ等の列挙要素）までは降りない。
列挙要素は親の号の柱書きがないと意味をなさず、単体では条件の断片になるため。

全チャンクに、法令名・法令ID・沿革ID・条番号・条見出し・
本則/附則の区別をメタデータとして付与し、分割された場合でも
出典と位置が特定できる状態を保つ。

### Consequences

* Good: チャンク境界が出典の単位と一致し、検索結果をそのまま根拠として提示できる
* Good: 区切りの妥当性が立法段階で保証されており、意味の途中で切れない
* Good: 条内の相対参照（「前項」等）がチャンク内で解決する
* Good: 情報の切り捨てが発生しない。暫定閾値 2,000 文字は技術上限（約17,000文字）を
  大きく下回る
* Bad: 分割ロジックが階層的になり、実装が複雑になる
* Bad: 同一の条が複数チャンクに分かれた場合、検索で一方だけがヒットして
  文脈が欠ける可能性がある
  → メタデータの条番号により、同一条の他チャンクを取得できる設計とする
* Bad: 分割を発動する閾値が未確定であり、暫定値で実装を進めることになる。
  第3週の比較実験の結果次第では、チャンク生成をやり直す必要がある
* Bad: トークン比率の実測は現代語の省令1本（登録認証機関等に関する規則、133条、
  67〜452字）のみ。カタカナ文語体の法令で同じ比率になるかは未検証
* Bad: 長大条文の構成要素と項の文字数分布は、重複を含む当初測定の値のままである
* Bad: 本ADRの測定対象は現行版の本則のみである。未施行版の差分チャンク（ADR-0017）や
  附則（ADR-0004）については別途分布を測定していない
