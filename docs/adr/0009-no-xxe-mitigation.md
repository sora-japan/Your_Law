# ADR-0009: XXE（XML外部実体参照）対策を実装しない

## Context and Problem Statement

XMLパーサーの一般的な脆弱性として XXE（XML External Entity）がある。
悪意あるXMLに外部実体参照を仕込むことで、ローカルファイルの読み出しや
サーバサイドリクエストフォージェリを引き起こす攻撃である。

XMLを扱う実装では、外部実体解決の無効化が推奨されることが多い。

## Decision Drivers

* 対策の要否は、攻撃者が入力XMLを供給できるかどうかで決まる
* 実装しない処理を増やさないこと
* 検討した事実を記録に残すこと

## Considered Options

1. 外部実体解決を明示的に無効化する処理を実装する
2. 実装せず、判断の根拠を記録する

## Decision Outcome

Chosen option: "実装せず、判断の根拠を記録する", because
XXE が成立する前提は、攻撃者が任意のXMLをパーサーに供給できることである。
本プロダクトがパースするのは e-Gov（デジタル庁）が配布する法令XMLのみであり、
利用者からXMLを受け取る経路は存在しない。

したがって攻撃経路が存在せず、対策を実装しても実効性がない。

ただし将来、利用者が独自のXMLをアップロードする機能を追加する場合は、
本判断は無効となり、再検討が必要である。

### Consequences

* Good: 不要な処理を実装せずに済む
* Good: 脆弱性を検討したうえで不要と判断した記録が残る
* Bad: 将来ユーザー入力のXMLを扱う機能を追加した際、この判断を見直す必要がある
  → 再検討条件を本ADRに明記することで対応する
