# ADR-0016: 同一施行日の複数バージョンを1つに絞らず、すべて保持する

## Context and Problem Statement

同一法令・同一施行日のファイルが複数存在するグループが 86 件ある。
最多は地方税法（`325AC0000000226`）の `20270401` で6件。

e-Gov のドキュメントによれば、これは施行期日が未確定で前後しうる
複数の改正規定が存在する場合に発生する。2つの改正法令 P と Q の
施行期日が前後しうるとき、その中間での状態は A_P と A_Q の2種類存在し、
**改正法令の施行期日順のパターンごとに、未来の状態が事前に確定する**とされる。

当初「改正法令IDが最新のバージョンが、他のバージョンの内容をすべて含んでいる」
という仮説を立て、86グループすべてで条番号の包含関係を検証した。
85グループでは欠落0だったが、1グループで反例が出た。

`323M40000100050` の `20270401`:

| 改正法令ID | 第30条の28の2〜4 |
|---|---|
| 508M60000100084 | あり |
| 508M60000100119 | **なし** |

番号が大きい `119` を候補とすると、`084` にある3条が欠落する。
2つのバージョンは包含関係になく、どちらも正しい未来の姿である。

地方税法で本則文字数が改正法令ID順に単調増加していたのは、
逐次適用の関係にあった偶然であり、一般則ではなかった。

## Decision Drivers

* 条文の欠落は、誤った法的判断に直結する
* どちらのバージョンも「正しい未来の姿」であり、一方を誤りとする根拠がない
* 同一条文が複数ヒットして検索結果を占有するのを避けたい

## Considered Options

1. 改正法令IDが最新のバージョンのみを保持する
2. 内容ベースで重複排除する
3. 全バージョンを保持し、施行日と改正法令IDをメタデータに持つ

## Decision Outcome

Chosen option: "全バージョンを保持し、施行日と改正法令IDをメタデータに持つ", because
選択肢1は上記の反例により、条文が欠落する。

選択肢2も成立しない。後のバージョンで条が削除されている場合、
古いバージョンにしか存在しない条は「重複」ではないため排除されず、
**削除されたはずの条文を提示する**結果になる。

選択肢3であれば欠落も誤提示も発生しない。
ただし同一条文が複数バージョンに存在するため、
インデックスの重複は ADR-0017 の差分方式で解消する。

同一施行日に複数バージョンが存在する条を提示する際は、
「他の改正との施行順により内容が異なる可能性があります」旨を併記する。

### Consequences

* Good: 条文の欠落が発生しない
* Good: 施行順が未確定であるという事実を、利用者に正しく伝えられる
* Good: 判断が全86グループの検証に基づいており、反例を根拠として示せる
* Bad: 同一施行日の複数バージョンをどう提示するかの UI 設計が必要になる
* Bad: 利用者にとって「どちらが正しいのか」が確定しない情報を返すことになる
  → 曖昧さを隠さず明示する方針とする（ADR-0011 の網羅性を保証しない方針と同じ姿勢）
