# ADR-0029: 附則をすべてインデックス対象に含める

## Context and Problem Statement

ADR-0004 で本則と附則を分離して保持する方針を定めたが、
「附則をインデックス対象に含めるかはチャンク設計時に再検討する」と先送りにしていた。
附則は 361,881 件存在し、全件をチャンク化すると検索対象が大きく膨らむためである。

附則の構造を調査した（`SupplProvision` 直下のタグ）。

| タグ | 件数 |
|---|---|
| Article | 573,217 |
| SupplProvisionLabel | 361,881（附則数と一致） |
| Paragraph | 241,434 |
| SupplProvisionAppdxTable | 2,247 |
| SupplProvisionAppdxStyle | 542 |
| Chapter | 14 |
| SupplProvisionAppdx | 2 |

本則と同じく「条がある附則」と「条がない附則」の2パターンがあり、
章が挟まる例も14件ある。全 `Article` 1,124,588 件のうち附則側が 573,217 件を占める。

附則1件あたりの文字数分布は以下のとおり。

| 区間 | 件数 | 割合 |
|---|---|---|
| 〜200 | 260,661 | **72.0%** |
| 201〜500 | 46,222 | 12.8% |
| 501〜1,000 | 24,293 | 6.7% |
| 1,001〜2,000 | 12,907 | 3.6% |
| 2,001〜5,000 | 9,490 | 2.6% |
| 5,001〜8,000 | 3,166 | 0.9% |
| 8,001〜 | 5,142 | 1.4% |

最大は 414,084 文字で、本則の最大（246,498）より大きい。

200文字以下の附則の中身を確認したところ、施行期日のみの規定であった。

```
附　則この省令は、公布の日から施行する。
附　則この省令は、平成七年六月一日から施行する。
附　則この省令は、平成九年四月一日から施行する。
```

教科用図書検定規則では18個の附則のうち15個が200文字以下で、すべてこの形式であった。
同一の文言が法令をまたいで大量に重複することになる。

## Decision Drivers

* 条文の取りこぼしが誤った回答に直結すること
* 短い附則が検索結果を占有する可能性があること
* 「意味がある附則」を機械的に判定する根拠が存在しないこと

## Considered Options

1. 全附則をチャンク化する
2. 文字数で足切りする（200文字以下を除外、101,220件に減る）
3. 施行期日のみの附則を判定して除外する
4. 附則をチャンク化せず、施行日情報のみメタデータに持つ

## Decision Outcome

Chosen option: "全附則をチャンク化する", because
選択肢2・3は「短い附則＝価値がない」という前提に立つが、**この前提を裏付ける根拠がない**。

確認したサンプルは2法令のみであり、26万件の附則がすべて施行期日のみとは言えない。
1項しかない附則にも「この省令の施行前にした申請については、なお従前の例による」のような
経過措置が書かれている可能性があり、「項が2つ以上あるか」といった指標も
絞り込みの目安にはなるが判定の根拠にはならない。

文字列で「施行する」のみかを判定する案も検討したが、表現の揺れ
（「施行する」「適用する」「効力を生ずる」「政令で定める日から施行する」）を
網羅できる保証がなく、それ自体が推測になる。

選択肢4は、経過措置が長文で書かれた附則（8,000文字超が5,142件）を失う。

したがって、根拠のないまま取りこぼしのリスクを負う判断は行わない。
**全件を含めたうえで、附則が検索結果を汚しているかは評価データで実測して判断する。**
評価の結果、附則が精度を下げていることが確認できた時点で、
除外の方針を再検討する。

### Consequences

* Good: 条文の取りこぼしが発生しない
* Good: 経過措置・施行期日の情報が保持され、改正検知という主機能に寄与する
* Good: 除外の判断を評価結果に基づいて行えるようになる
* Bad: チャンク総数がほぼ倍増する（現行版で本則 400,308 + 附則 305,716 = 706,024）。
  埋め込みのコストと時間がその分増える
* Bad: 「この省令は、公布の日から施行する」のような同一文言のチャンクが
  大量に存在し、検索結果を占有する可能性がある
* Bad: 除外すべきかの判断を先送りしており、評価の段階で再検討が必要
