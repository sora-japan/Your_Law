# ADR-0018: 削除される条は現行版チャンクのメタデータとして扱う

## Context and Problem Statement

未施行版との差分を取る際、現行版にのみ存在し未施行版にない条、
すなわち**将来削除される条**が検出される。

複数バージョンを持つ 856 法令を対象に実測した結果:

| 項目 | 件数 |
|---|---|
| 削除が発生した法令 | 57（6.7%） |
| 削除される条の総数 | 499 |

削除される条が実体を持つかを確認するため、内閣府設置法（`411AC0000000089`）の
現行版（`20260717`）を調査した。2026年12月31日に削除される
第9条の2および第16条の2は、いずれも200字前後の実質的な条文であった
（防災担当の特命担当大臣の設置規定、防災監の設置規定）。
「第◯条　削除」とだけ記された空の条ではない。

削除される条は、未施行版に本文が存在しない。
したがって差分チャンクとして本文を持つことができない。

## Decision Drivers

* 想定利用者は法律の専門家ではなく、条番号を指定して検索しない
* 現在有効な条文は、削除予定であっても現時点では有効である
* 数か月後に消える規定を、そうと知らせずに提示するのは不適切

## Considered Options

1. 削除を扱わない
2. 「この条は削除されます」という本文なしのチャンクを作る
3. 現行版チャンクのメタデータとして削除日と根拠を持たせる

## Decision Outcome

Chosen option: "現行版チャンクのメタデータとして削除日と根拠を持たせる", because
選択肢1では、利用者が「現在有効」とだけ認識し、
数か月後に根拠を失うことに気づけない。

選択肢2は本文を持たないため、意味検索で引くことができない。
想定利用者は「防災の担当大臣について知りたい」のように内容で検索するのであり、
条番号を指定しない。本文のないチャンクは検索対象として機能しない。

選択肢3であれば、通常の意味検索で現行版の条が引けた際に、
その条が削除予定であることを併せて提示できる。
これは ADR-0006（本則が抄録の法令に注記を添える）と同じ設計方針であり、
「能動的に通知するのではなく、引けたときに注記する」という一貫性を保つ。

メタデータに持たせる項目は、削除される施行日と、根拠となる改正法令ID。

なお同一の条が複数バージョンで削除されているケースが観測された
（内閣府設置法の第9条の2・第16条の2は3バージョンで削除）。
これは「どの施行順パターンでも削除される」ことを意味するため、
メタデータとしては最も早い削除日に集約してよい。

### Consequences

* Good: 通常の意味検索の流れの中で、削除予定を伝えられる
* Good: ADR-0006 と同じ「引けたときに注記する」方針で一貫する
* Good: 本文のない検索不能なチャンクを作らずに済む
* Bad: 削除日が確定していない場合（ADR-0019 の施行日未定）の表現が必要になる
* Bad: 削除された条の「削除後の状態」を提示できない。
  利用者が「では今後どうなるのか」を知るには e-Gov を参照する必要がある
