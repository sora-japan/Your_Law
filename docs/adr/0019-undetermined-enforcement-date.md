# ADR-0019: 施行日 2100年以降を「施行日未定」として扱う

## Context and Problem Statement

ファイル名の施行日部分を年ごとに集計したところ、
現実的な日付（1872年〜2035年）の範囲外に以下の値が存在した。

| 値 | 件数 |
|---|---|
| 21171231 | 37 |
| 21171230 | 3 |

合計40件、全ファイルの約0.4%。

該当ファイル（畜産経営の安定に関する法律施行令、`336CO0000000387`）の
附則を確認したところ、施行期日が以下のように規定されていた。

* 平成三〇年一二月二八日政令第三六一号:
  環太平洋パートナーシップ協定が日本国について効力を生ずる日から施行
* 平成二九年一月二五日政令第七号:
  環太平洋パートナーシップに関する包括的及び先進的な協定が
  日本国について効力を生ずる日から施行

e-Gov のドキュメントにも、施行期日は「政令で定める日」のように指定でき、
その場合**具体的にいつ施行されるかは公布の段階では確定していない**と記載がある。

すなわち `21171231` は実在の日付ではなく、
施行日が確定していないことを表す値であると考えられる。
`21171230` が3件存在するのは、未確定なもの同士の順序関係を
保持するための調整と推測されるが、確認できていない。

## Decision Drivers

* 「2117年12月31日に施行されます」と表示することは明白な誤りである
* 施行日が確定していないという事実自体が、利用者にとって意味のある情報である
* 判定条件は単純であるほど保守しやすい

## Considered Options

1. 該当ファイルを除外する
2. 値をそのまま日付として扱う
3. 施行日が 2100年以降のものを「施行日未定」として扱う

## Decision Outcome

Chosen option: "施行日が 2100年以降のものを「施行日未定」として扱う", because
選択肢1は、公布済みで内容が確定した改正規定を失うことになる。
条約の発効に伴う改正など、実際に効力を持ちうるものが含まれる。

選択肢2は誤った日付を提示する。

選択肢3であれば、`21171231` と `21171230` の両方を1つの条件でカバーでき、
将来 e-Gov 側が別の番兵値を用いた場合にも対応できる可能性が高い。
現実の法令で 2100年以降の施行日が指定されることは想定しにくいため、
誤判定のリスクは小さい。

該当する条を提示する際は、施行日の代わりに
「施行日未定」と表示し、可能であれば附則の施行期日規定を併せて示す。

### Consequences

* Good: 誤った日付の提示を防げる
* Good: 判定条件が単純で、番兵値の種類が増えても対応できる
* Good: 施行日が未確定であるという事実を利用者に伝えられる
* Bad: `21171231` が番兵値であることは実データからの推測であり、
  e-Gov の公式仕様で確認できていない
  → 仕様上の裏付けが取れた時点で本ADRを更新する
* Bad: `21171230` と `21171231` の差の意味が不明のまま。
  両方を「未定」として扱うため、順序関係の情報があれば失われる
